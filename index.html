Getting started

Start building today

Five steps take you from browsing the catalog to a live production integration. Steps 2 and 4 run in parallel, so contracting never blocks your build.

1

Browse and pick your APIs

Explore the catalog across onboarding, accounts, payments, mobile load, transfers, cards, and acquiring, and identify what your use case needs.

Browse the API catalog →
2

Create your free accountinstant

Self-registration takes a couple of minutes. You get a Client ID and Client Secret immediately — no manual approval wait to start testing.

Create a free account →
3

Build and test in the sandbox

Every API ships with full documentation, request and response schemas, sample code in six languages, and a live "try it" console against synthetic test data.

Open the sandbox console →
4

Run business onboardingruns in parallel

While you build, our business team runs the commercial and compliance track alongside you:

  • Partner onboarding and use-case review
  • Contract signing and commercial agreement
  • Operational process and security review
5

Go live in production

Once your agreement is signed and sandbox testing is complete, request production access from the console. A production Client ID and Client Secret are issued per app — the secret is shown once, so store it securely.

Go to console →
